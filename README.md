# 🎮 Game Agent Practice

게임을 스스로 플레이하는 AI 에이전트를 직접 만들어 보며 배우는 연습 저장소입니다.

간단한 환경에서 출발해 점점 더 복잡한 게임으로 넓혀 가며,
에이전트가 **보고(관찰) → 판단하고(행동) → 결과로 배우는(보상)** 과정을 하나씩 실험합니다.

## 다루는 방향
- **강화학습(RL)**: 보상을 통해 시행착오로 플레이 방법을 스스로 익히는 에이전트
- **LLM 에이전트**: 언어 모델이 게임 상황을 이해하고 다음 행동을 고르는 에이전트

## 프로젝트
| 프로젝트 | 방식 | 한 줄 소개 |

| [CartPole](cartpole/) | RL (PPO) | 수레를 움직여 막대의 균형 잡기 |
