강화학습 대신 **LLM(언어 모델)에게 판을 글로 보여주고 다음 수를 고르게** 하는 에이전트입니다.
코랩에 내장된 `google.colab.ai`(Gemini)를 사용해서 API 키 없이 실행할 수 있습니다.

## 강화학습 에이전트와 비교

| | 강화학습 (CartPole, FrozenLake) | LLM 에이전트 (이번) |
|---|---|---|
| 학습 | 수천 판 플레이하며 학습 | **학습 없음** (이미 학습된 모델 사용) |
| obs | 숫자 | **글** (판 상태를 텍스트로) |
| 행동 고르기 | 신경망/표의 점수 | **프롬프트 → LLM 답변 → 파싱** |
| 실력을 올리는 방법 | 더 학습 | **프롬프트 개선** |

## 동작 방식

```
판 상태 → [글로 변환] → [프롬프트] → LLM → 답변 → ['MOVE: 5'에서 숫자 추출] → 행동
```

LLM이 보는 판은 이렇게 생겼습니다. 빈칸에는 칸 번호를 적어서 LLM이 보이는 숫자 중 하나를 고르기만 하면 되도록 했습니다.
```
 X | 2 | 3
---+---+---
 4 | O | 6
---+---+---
 7 | 8 | X
```

### 잘못된 수 처리
LLM은 이미 찬 칸을 고르거나 형식에 맞지 않게 답하기도 합니다.
그래서 **둘 수 없는 칸이면 이유를 알려주고 다시 묻고**, 3번 실패하면 랜덤으로 둡니다.
잘못된 수가 몇 번 나왔는지도 기록합니다.

## 비교 상대

| 상대 | 설명 |
|---|---|
| 랜덤 봇 | 아무 칸에나 둠. 가장 약한 기준 |
| 미니맥스 봇 | 모든 경우의 수를 끝까지 계산하는 **완벽한 플레이어**. 절대 지지 않으므로 LLM의 최선은 무승부 |

## 실험: 프롬프트 개선

같은 LLM에 두 가지 프롬프트를 주고 랜덤 봇, 미니맥스 봇과 각각 6판씩 대전해 비교합니다.

- **기본 프롬프트**: 규칙과 판만 알려줌
- **전략 프롬프트**: "바로 이길 수 있으면 이기기 → 상대가 이기려 하면 막기 → 포크 → 가운데 → 모서리" 순서로 확인하게 함

## 배운 점
- LLM 에이전트는 학습 없이 **프롬프트 설계만으로** 행동을 바꿀 수 있다.
- LLM의 답변은 자유로운 글이라서, 정해진 형식(`MOVE: 숫자`)을 요구하고 **파싱과 오류 처리**를 꼭 해야 한다.
