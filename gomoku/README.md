# Gomoku AlphaZero Agent

15×15 **오목(렌주룰)**을 **ResNet + MCTS 자기대전(AlphaZero 방식)**으로 학습하는 에이전트입니다.
[아발론](../abalone/)과 같은 구조이고, Google Colab 무료 GPU(T4)에서 돌아가도록 만들었습니다.

## 규칙

기본은 **렌주룰**입니다 (1번 셀 `CFG['rule']`).

| 항목 | 흑 | 백 |
|---|---|---|
| 3-3 | 금수 | 허용 |
| 4-4 (한 줄 안의 `●_●●●_●` 포함) | 금수 | 허용 |
| 6목 이상 | 금수 | 승리 |
| 정확히 5목 | 승리 (금수보다 우선) | 승리 |
| 첫 수 | 천원(정중앙) | |

- 대회용 개시 규칙(스왑 등)은 생략했습니다.
- 3-3 판정: "한 수 더 두면 열린 4(`_●●●●_`)가 되는 줄"이 두 방향 이상이면 금수. 열린 4로 가는 자리가 다시 금수인지까지 따지는 정식 재귀 판정은 생략했습니다.
- 규칙 검증 셀에서 3-3, 띈 3, 막힌 3, 4-3, 가장자리, 5목 우선, 4-4, 한 줄 4-4, 6목(흑 금수 / 백 승리)을 확인합니다.

다른 규칙도 고를 수 있고, 체크포인트는 규칙마다 다른 폴더에 저장됩니다.

| `rule` | 내용 | 저장 폴더 |
|---|---|---|
| `'renju'` (기본) | 렌주룰 | `gomoku_renju_az/` |
| `'korean'` | 한국식: 흑백 모두 3-3 금지, 6목은 승리 아님(`exact_five=True`), 4-4 허용 | `gomoku_az/` |
| `'black'` | 흑만 3-3 금지 | `gomoku_black_az/` |
| `'none'` | 금지 없음 | `gomoku_none_az/` |

## 학습 방식

```
① 자기대전 → ② 리플레이 버퍼 → ③ 학습 모델 훈련 → ④ 아레나 대결 → ⑤ 교체 여부 결정 → ①
```

1. **자기대전**: 최고 모델로 MCTS(수당 200회 탐색) 64판. 그중 40%는 휴리스틱 봇과 두고 AI 쪽 국면만 학습에 사용
2. **리플레이 버퍼**: 최근 15만 국면 보관, 8가지 회전·반사 대칭을 무작위 적용
3. **학습**: 정책(탐색 분포 따라 하기) + 가치(승패 예측) 손실로 400스텝, 계단식 학습률 `{0: 1e-3, 75: 3e-4, 150: 1e-4}`
   - 가치 목표는 판 길이를 반영: 승패 크기 = `1 - 0.5 × min(수, 100) / 100` (`len_shaping`, `len_scale`). 빨리 이길수록 +1에 가깝고, 오래 버티다 질수록 덜 나쁨
4. **아레나**: 학습 모델 vs 최고 모델 20판 (흑백 교대, 초반 4수 무작위)
5. **교체**: 55% 이상이면 최고 모델 교체
6. **평가**: 3번마다 최고 모델 vs 휴리스틱 / 미니맥스 각 20판. 오목은 흑백 유불리가 커서 흑·백 성적을 따로 기록

### 아발론에서 배운 것을 처음부터 반영

| 아발론에서 겪은 문제 | 오목에서 처음부터 넣은 것 |
|---|---|
| 탐색을 늘리자 서로 피하기만 하는 무승부로 수렴 (v3) | 자기대전의 일부(40%)를 휴리스틱 봇과 대국 (`heuristic_frac`) |
| 연습판 초반 무작위가 커서 의미 없는 패배만 쌓임 (v4) | 연습판은 초반 무작위 2수, 탐색 잡음 끔 (`heuristic_temp_moves`, `heuristic_noise`) |
| 학습 상대 승률이 그 봇 맞춤 실력일 수 있음 (v6) | 학습에 안 쓰는 평가 전용 미니맥스 봇 |
| 이길 수 있는데 마무리를 안 함 | 이길 수 있으면 바로 두고, 상대 5목 자리가 하나면 바로 막기 (`tactical_override`) |
| 승패만 주는 거친 보상보다 촘촘한 신호가 중요 (v2) | 판 길이를 반영한 가치 목표 (`len_shaping`) |

## 구성

| 구성 요소 | 내용 |
|---|---|
| 게임 환경 | 15×15, 규칙 판정은 numba로 가속 |
| 행동 공간 | 225칸 (금수·돌 있는 칸은 마스크) |
| 신경망 | ResNet (64채널, 잔차 블록 6개, 약 0.45M 파라미터), 완전 합성곱 정책 헤드 + 가치 헤드 |
| 입력 | 15×15×5 (내 돌, 상대 돌, 마지막 수, 흑 차례 여부, 금수 자리) |
| 탐색 | PUCT 기반 MCTS, 여러 판의 잎 노드를 묶어 GPU 배치 평가 |
| 비교 상대 | 랜덤, 휴리스틱(한 수 앞: 공격 점수 + 0.9 × 수비 점수), 미니맥스(평가 전용: 내 후보 8수 × 상대 응수 8수) |

## 실행 방법

1. `gomoku_alphazero.ipynb`를 Google Colab에서 열기
2. `런타임 → 런타임 유형 변경 → T4 GPU` 선택
3. `모두 실행` → 구글 드라이브 연결 허용
4. 학습은 **9번 셀**에서 돌아갑니다. 체크포인트는 `MyDrive/gomoku_renju_az/`에 반복마다 저장되고, 세션이 끊겨도 다시 실행하면 이어서 학습
5. AI와 두기: 1, 2, 4\~8번 셀 실행 후 **12번 셀(판 클릭, 바둑알 모양 판)** 또는 11번 셀(좌표 입력). 9번 학습 셀은 건너뛰기
6. 자기대전 들여다보기: 1, 2, 4\~8번 셀 실행 후 **13번 셀**. `watch_selfplay()`로 한 판을 착수 번호와 함께 보고, `analyze_selfplay(10)`으로 패배 원인(이중 위협 / 금수 유도) 통계를 냄. CPU 런타임으로도 충분

Colab 밖(로컬 Jupyter, 코랩 로컬 런타임)에서는 드라이브 대신 현재 폴더(`./gomoku_renju_az/` 등)에 저장합니다.

## 결과

### 렌주룰 1차 (반복 0\~23회, Colab 무료 T4, 반복당 약 3\~7분)

설정: 탐색 128회, 휴리스틱 판 25%, 가치 목표 = 승패(±1)

| 반복 | 정책 손실 | 가치 손실 | 평균 수 | 자기대전 흑승/백승 | vs휴리스틱 | vs미니맥스 |
|---|---|---|---|---|---|---|
| 0 | 5.07 | 0.46 | 76 | 42% / 58% | 0% | 0% |
| 9 | 4.21 | 0.28 | 39 | 44% / 56% | 2% | 0% |
| 15 | 4.02 | 0.26 | 21 | 79% / 21% | 0% | 0% |
| 21 | 3.84 | 0.22 | 18 | 12% / 88% | 5% | 0% |
| 23 | 3.77 | 0.23 | 26 | 17% / 83% | - | - |

- 정책 손실은 꾸준히 감소, 아레나 24번 중 13번 교체로 학습 자체는 진행
- **자기대전 쏠림**: 10\~15회는 흑 73\~79%, 16\~23회는 백 83\~98%. 판이 16\~27수에 끝남
- 평가는 휴리스틱 0\~5%, 미니맥스 0\~2%로 거의 오르지 않음 → 자기 약점만 찌르는 수순을 배운 것
- 13번 셀로 본 자기대전: 백이 한 줄에 열린 3 → 열린 4를 만드는 동안 흑이 엉뚱한 곳에 둠. **금수 유도가 아니라 흑이 열린 3을 막는 기본 수비를 못 하는 상태**. 흑이 거의 모든 판을 져서 "뭘 둬도 진다"고 배운 탓

### 렌주룰 2차 (반복 24회\~, 진행 중)

1차의 쏠림에 대응해 바꾼 것 (모델은 이어서 학습, 예전 버퍼는 가치 목표가 달라 한 번 비움)

- **판 길이 반영 가치 목표** (`len_shaping=0.5`): 열린 3을 막아 오래 버티면 진 판이어도 덜 나쁜 값 → 흑에게 수비 신호
- **휴리스틱 판 25% → 40%**: 꼬박꼬박 막는 상대와 두며 배우기
- **탐색 128 → 200회**: 4-3, 금수 유도 같은 위협을 더 깊이 읽기
- **학습량을 버퍼 크기에 맞춤** (`max_reuse=4`, 반복 41\~): 버퍼를 비운 직후 3\~5천 국면으로 매 반복 400스텝(약 10만 개)을 학습해 가치 손실이 0.08\~0.10까지 떨어짐(데이터 암기). 스텝 = `min(400, 버퍼 × 4 / 배치)`로 바꿔 국면당 평균 4번만 보게 함

반복 36\~40 (판 길이 반영 직후): 자기대전 백승 92\~100%, 평균 22\~28수로 아직 쏠림이 남아 있지만, 연습판 vs휴리스틱은 4% → 19%로 상승

반복 45\~56: 평균 수 26 → 최대 47수로 늘고, 평가에서 처음으로 AI가 흑으로 점수를 땀(54회 휴리스틱 상대 흑 15% / 백 60%). 하지만 자기대전 백승은 여전히 89\~100%. 13번 셀로 본 판에서 흑은 백의 열린 3(G7·G8·G9)을 막지 않고 가장자리에 두다가 열린 4로 짐. **흑의 정책이 거의 평평해서 탐색도 평평해지고, 그 결과를 배운 정책이 다시 평평해지는 악순환**으로 판단

- **휴리스틱에게 기본 수비 빌려오기** (반복 57\~, 자기대전 데이터에만 적용)
  - `teacher_samples=True`: 휴리스틱 판에서 휴리스틱이 둔 수도 정답(one-hot)으로 학습
  - `heur_prior=0.25`: 자기대전 탐색의 루트 사전확률에 휴리스틱 점수를 25% 섞음 (`p ∝ (1 + 점수)^2`). 백 열린 3 국면에서 막는 두 자리에 휴리스틱 확률의 97%가 몰림
  - 아레나·평가·사람과의 대국은 신경망과 탐색만 사용하므로 평가 점수는 AI 자신의 실력
