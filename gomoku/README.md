# Gomoku AlphaZero Agent

15×15 **오목(렌주룰)**을 **ResNet + MCTS 자기대전(AlphaZero 방식)**으로 학습하는 에이전트입니다.
[아발론](../abalone/)과 같은 구조이고, Google Colab 무료 GPU(T4)에서 돌아가도록 만들었습니다.

## 규칙

기본은 **렌주룰**입니다 (1번 셀 `CFG['rule']`).

| 항목 | 흑 | 백 |
|---|---|---|
| 3-3 | 금수 | 허용 |
| 4-4 (한 줄 안의 `●_●●●_●` 포함) | 금수 | 허용 |
| 6목 이상 | 금수 | 승리 |
| 정확히 5목 | 승리 (금수보다 우선) | 승리 |
| 첫 수 | 천원(정중앙) | |

- 대회용 개시 규칙(스왑 등)은 생략했습니다.
- 3-3 판정: "한 수 더 두면 열린 4(`_●●●●_`)가 되는 줄"이 두 방향 이상이면 금수. 열린 4로 가는 자리가 다시 금수인지까지 따지는 정식 재귀 판정은 생략했습니다.
- 규칙 검증 셀에서 3-3, 띈 3, 막힌 3, 4-3, 가장자리, 5목 우선, 4-4, 한 줄 4-4, 6목(흑 금수 / 백 승리)을 확인합니다.

다른 규칙도 고를 수 있고, 체크포인트는 규칙마다 다른 폴더에 저장됩니다.

| `rule` | 내용 | 저장 폴더 |
|---|---|---|
| `'renju'` (기본) | 렌주룰 | `gomoku_renju_az/` |
| `'korean'` | 한국식: 흑백 모두 3-3 금지, 6목은 승리 아님(`exact_five=True`), 4-4 허용 | `gomoku_az/` |
| `'black'` | 흑만 3-3 금지 | `gomoku_black_az/` |
| `'none'` | 금지 없음 | `gomoku_none_az/` |

## 학습 방식

```
① 자기대전 → ② 리플레이 버퍼 → ③ 학습 모델 훈련 → ④ 아레나 대결 → ⑤ 교체 여부 결정 → ①
```

1. **자기대전**: 최고 모델로 MCTS(수당 128회 탐색) 64판. 그중 25%는 휴리스틱 봇과 두고 AI 쪽 국면만 학습에 사용
2. **리플레이 버퍼**: 최근 15만 국면 보관, 8가지 회전·반사 대칭을 무작위 적용
3. **학습**: 정책(탐색 분포 따라 하기) + 가치(승패 예측) 손실로 400스텝, 계단식 학습률 `{0: 1e-3, 75: 3e-4, 150: 1e-4}`
4. **아레나**: 학습 모델 vs 최고 모델 20판 (흑백 교대, 초반 4수 무작위)
5. **교체**: 55% 이상이면 최고 모델 교체
6. **평가**: 3번마다 최고 모델 vs 휴리스틱 / 미니맥스 각 20판. 오목은 흑백 유불리가 커서 흑·백 성적을 따로 기록

### 아발론에서 배운 것을 처음부터 반영

| 아발론에서 겪은 문제 | 오목에서 처음부터 넣은 것 |
|---|---|
| 탐색을 늘리자 서로 피하기만 하는 무승부로 수렴 (v3) | 자기대전의 25%를 공격적인 휴리스틱 봇과 대국 (`heuristic_frac`) |
| 연습판 초반 무작위가 커서 의미 없는 패배만 쌓임 (v4) | 연습판은 초반 무작위 2수, 탐색 잡음 끔 (`heuristic_temp_moves`, `heuristic_noise`) |
| 학습 상대 승률이 그 봇 맞춤 실력일 수 있음 (v6) | 학습에 안 쓰는 평가 전용 미니맥스 봇 |
| 이길 수 있는데 마무리를 안 함 | 이길 수 있으면 바로 두고, 상대 5목 자리가 하나면 바로 막기 (`tactical_override`) |

## 구성

| 구성 요소 | 내용 |
|---|---|
| 게임 환경 | 15×15, 규칙 판정은 numba로 가속 |
| 행동 공간 | 225칸 (금수·돌 있는 칸은 마스크) |
| 신경망 | ResNet (64채널, 잔차 블록 6개, 약 0.45M 파라미터), 완전 합성곱 정책 헤드 + 가치 헤드 |
| 입력 | 15×15×5 (내 돌, 상대 돌, 마지막 수, 흑 차례 여부, 금수 자리) |
| 탐색 | PUCT 기반 MCTS, 여러 판의 잎 노드를 묶어 GPU 배치 평가 |
| 비교 상대 | 랜덤, 휴리스틱(한 수 앞: 공격 점수 + 0.9 × 수비 점수), 미니맥스(평가 전용: 내 후보 8수 × 상대 응수 8수) |

## 실행 방법

1. `gomoku_alphazero.ipynb`를 Google Colab에서 열기
2. `런타임 → 런타임 유형 변경 → T4 GPU` 선택
3. `모두 실행` → 구글 드라이브 연결 허용
4. 학습은 **9번 셀**에서 돌아갑니다. 체크포인트는 `MyDrive/gomoku_renju_az/`에 반복마다 저장되고, 세션이 끊겨도 다시 실행하면 이어서 학습
5. AI와 두기: 1, 2, 4~8번 셀 실행 후 **12번 셀(판 클릭, 바둑알 모양 판)** 또는 11번 셀(좌표 입력). 9번 학습 셀은 건너뛰기

Colab 밖(로컬 Jupyter, 코랩 로컬 런타임)에서는 드라이브 대신 현재 폴더(`./gomoku_renju_az/` 등)에 저장합니다.

## 결과

### 한국식 규칙 (반복 0~25회, Colab 무료 T4, 반복당 약 5~8분)

렌주룰로 바꾸기 전, 한국식 규칙(`rule='korean'`)으로 학습한 초반 결과입니다. 렌주룰은 처음부터 다시 학습합니다.

| 반복 | 정책 손실 | 평균 수 | 자기대전 흑승 | vs휴리스틱 | vs미니맥스 |
|---|---|---|---|---|---|
| 0 | 5.09 | 74 | 46% | 0% | 0% |
| 12 | 4.21 | 30 | 77% | 2% | 0% |
| 18 | 3.93 | 25 | 90% | 8% | 5% |
| 24 | 3.72 | 36 | 65% | 12% | 10% |

- 정책 손실이 매 반복 꾸준히 감소 (5.09 → 3.69). 225칸 무작위 착수의 값은 약 5.4
- 휴리스틱 상대 0% 탈출이 12회차 (아발론은 45회차)
- 평균 수 74 → 30 안팎: 5목 만드는 공격은 익혔지만 수비가 아직 약한 단계. 둘 다 수비가 약해 선수인 흑의 승률이 73~90%까지 오름
- 아레나 무승부 0~2판으로 소극적 플레이 수렴 징후 없음
- 가치 손실은 1회차부터 약 0.30에서 유지

## 다음에 볼 것

- 렌주룰에서는 흑이 금수로 크게 제한되므로, 자기대전 흑승·백승 균형이 한국식과 어떻게 다른지
- 평균 수가 다시 늘어나는지 (수비를 배우는 신호)
- 휴리스틱 상대가 50~80회쯤 30~50%까지 오르는지
- 흑승이 계속 90% 근처면 백 쪽 데이터가 대부분 패배라 학습이 어려움
